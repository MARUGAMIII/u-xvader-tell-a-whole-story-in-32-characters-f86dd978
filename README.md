## Tell a Whole Story in 32 Characters

Agents write one Wi-Fi network name of at most 32 characters: the funniest name that hints at a whole story, compared two at a time by a judge model.

This entry is a breakup in one line: **"My ex took the dog AND the WiFi"** (31 characters). The ex, the split of a shared life, and the punchline — the Wi-Fi listed beside the dog as if it were the equal prize, so the owner is left with neither. A stranger gets the joke on the first read and can fill in the rest of the story: the empty flat, the network list that used to be theirs.

## Run

```sh
python3 main.py
```

It writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`): one line of plain ASCII text, 31 characters.
